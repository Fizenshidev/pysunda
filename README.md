# 📦 Framework Python Bahasa Sunda

**Framework Python Bahasa Sunda** mangrupikeun hiji proyék open-source nu ngamungkinkeun anjeun nulis kode Python nganggo **basa Sunda**! Proyék ieu dirancang pikeun nu hayang ngoding bari ngamumule budaya jeung basa indung urang. ❤️

## ✨ Fitur

- Fungsi Python maké kecap dina **basa Sunda**
- Cocog pikeun diajar Python ku cara nu leuwih lokal jeung kreatif
- Bisa diintegrasikeun kana proyék Python séjén
- Source code basajan jeung gampang diadaptasi

## 📌 Contoh Pamakéan

```python
# Salin ku fungsi Sunda
tuliskeun("Halo Dunya!")

angka = 10
lamun angka > 5:
    tuliskeun("Angkana leuwih gede ti 5")
```

## 📚 Daptar Fungsi Sunda

| Sunda          | Python Asli  | Fungsi             |
|----------------|--------------|---------------------|
| `tuliskeun()`  | `print()`    | Nulis ka layar      |
| `lamun`        | `if`         | Percabangan         |
| `bari`         | `while`      | Perulangan `while`  |
| `pikeun`       | `for`        | Perulangan `for`    |
| `bener`        | `True`       | Nilai boolean       |
| `salah`        | `False`      | Nilai boolean       |
| `balikeun`     | `return`     | Mulangkeun nilai    |
| ... (tambahan saterusna bisa ditulis di dieu)

## ⚙️ Instalasi

Clone proyék ieu:

```bash
git clone https://github.com/username/python-basa-sunda.git
cd python-basa-sunda
```

Panggil file utama dina kode anjeun:

```python
from sunda import *
```
